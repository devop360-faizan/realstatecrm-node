# RealEstate CRM — Backend API

## Tech Stack
- **Runtime**: Node.js (CommonJS)
- **Framework**: Express.js
- **Database**: MySQL
- **ORM**: Prisma
- **Auth**: JWT (Access + Refresh Token)
- **Validation**: express-validator
- **Logging**: Winston
- **File Upload**: Multer

## Folder Structure
```
src/
├── config/           → DB, CORS, constants, multer configs
├── routes/           → Express routers (per module)
├── controllers/      → HTTP request/response handlers
├── services/         → Business logic (talks to Prisma)
├── middlewares/      → auth, authorize, validate, upload, errorHandler
├── validators/       → express-validator rule sets
├── resources/        → Response transformers (shape API output)
├── utils/            → ApiError, ApiResponse, asyncHandler, helpers
prisma/
├── schema.prisma     → All DB models/tables
├── migrations/       → Auto-generated by Prisma
├── seed.js           → Seed script
```

## Modules
1. Auth (login / register / refresh / logout)
2. Users (profile, avatar)
3. Properties (listings, images, status)
4. Clients / Leads
5. Agents / Staff
6. Deals / Contracts
7. Payments / Invoices
8. Dashboard / Reports

## Getting Started
```bash
npm install
npx prisma migrate dev
npm run dev
```
